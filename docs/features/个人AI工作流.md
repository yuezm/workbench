# 个人AI工作流

个人AI工作台

## 目的

我想研发自己的AI工作流，如下构想

1. 做为 Worker 接收远端的任务，即多台设备可以实现执行多个任务，只是设想，可以先设计架构，但是不实现
2. 本地支持不同的运行时工具，不同的工具擅长不同的事情
3. 可以自定义工作流，以单SOP或者SOP串联来完成大型任务
4. 由一个看板来查看当前任务的执行情况，在哪个阶段，不同的阶段有哪些任务

## 设施

### 本地运行

此App目前运行于本地，由入口派发任务

### 运行时

可以添加多个为运行时，例如可以添加 hermes agent、claude code、codex、deepSeek harness、oh-my-pi 等运行时（这些运行时都是我本地安装的 cli）。此实现可以参考 Multica 是怎么做的

### 智能体

可以添加智能体，以某个运行时做为智能体的配置，在调用智能体时，相当于在调用某个运行时。

智能体包含

1. 名称
2. 描述
3. 执行配置（运行时）
4. 能力（每次运行的时候的System Prompt）

详细的实现可以参考 Multica 是怎么做的

### 自定义的工作流

可以自定义工作流，工作流之间可以串

例如：研发工作流 待办 --> 进行中 --> 审核中 --> 已完成
例如：QA工作流 待办 --> 审核中 --> 已完成

每个工作流的阶段，可以选择

进入时

1. 进入时，不交接
2. 进入时，交给给某个智能体
3. 进入时，交接给某个用户，让用户自己决定，此时就需要人为干预审批了

完成时

1. 自动跳转到下一个阶段，例如审核中完成后，跳转到已完成
